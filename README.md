# WorldAI

本地 AI 角色扮演客户端，支持 Windows 11 x64 和 Android 8.0 及以上。下载见 [GitHub Releases](https://github.com/ZhixiTiancai/World-AI/releases)。

## 启动

双击同目录的 WorldAI.exe。首次打开会看到「雾港来信」示例会话，输入一句话后点击「发送」或按 Ctrl + Enter。离线演示只播放内置回复，不调用真实模型。

Android 下载 WorldAI-android.apk，通过系统安装器安装，并使用当前版本的 Android System WebView。Android 的「设置」会分别打开外观、聊天默认值、模型、玩家身份、提示词预设、备份恢复和软件更新页面。

要连接真实模型：

1. 打开「模型设置 → 添加模型」。
2. 填写 OpenAI 兼容 API 的基础地址或完整的 chat/completions 地址，以及 API 密钥。服务没有认证时，密钥可以留空。
3. 点「获取模型列表」，从下拉框选中模型。服务不提供模型列表时，可以直接输入模型 ID。
4. 点「测试连接」，收到回复后点「保存」。
5. 回到「对话」页，新建会话，或在当前会话的「设置」中选择刚添加的模型。

「角色卡」可以新建和导入；给角色挂载世界书后，对话右侧会显示当前命中的条目。「编辑记忆」可以手工添加重要事件，或生成并修改剧情摘要。「对话 → 导出」可导出 TXT 或 JSON。

「世界书 → 导出」可将单本世界书保存为 JSON，用于 WorldAI 或 SillyTavern 导入。导出包含名称、正文、关键词、启用状态和常驻标记。Android 可用相同格式导入导出世界书。

## 编辑角色卡

- 性格写进「背景与场景」。旧数据和导入卡片中独立的性格字段会合并进去。长文本可点「放大编辑背景」；示例对话点「示例对话」单独编辑。
- 「转换中文」用已配置的模型翻译背景、示例对话和全部开场白。译文先回填编辑草稿，点「保存」才会应用。挂载的世界书和角色名称不随卡片一起翻译。
- 主开场白和备选开场白分别编辑。新建会话时可预览、选择任意一条，也可以不使用开场白。角色卡导入和导出均支持备选开场白。

## 数据

数据默认写在 %LOCALAPPDATA%\WorldAI\world.json。API 密钥用 Windows 当前用户的凭据保护，整库导出的 JSON 不含密钥。聊天日志和其他内容保存在本机，调用远程模型时，当前回复所需的内容会发送到所配置的服务。

Windows 与 Android 支持互相导入整库备份。两端各自保存数据，移动端密钥由 Android Keystore 保护。如果迁移到另一端，请重新填写 API 密钥。

## 更新

- Windows 默认在启动时自动检查。在「全局设置 → 检查更新」可以手动检查。确认「下载并重启」后，程序校验 GitHub Release 的 SHA-256，替换本机程序并重启。数据目录不参与更新。
- Android 在「设置 → 检查更新」查看最新版，下载 APK 后由系统安装器确认。需要使用原发行密钥为新版本签名，才能覆盖安装并保留数据。

## 聊天设置

- **聊天背景**：Windows 点对话右上角「背景」；Android 点「更多 → 聊天背景」。可为当前会话选择 PNG 或 JPG、调整主题遮罩或恢复主题色。背景会随整库备份迁移，单独导出的聊天记录不包含图片。
- **全局玩家身份**：在「玩家身份」页给常用身份点「设为全局」。未单独指定身份的会话会跟随全局，可在会话设置另选身份或选「不使用玩家身份」。
- **全局设置**：新会话默认模型、全局提示词、发送的历史条数和字数上限、聊天窗口每次加载的消息条数、窗口置顶。
- **外观**：在「全局设置 → 外观」选雾紫、柔红、灰绿、浅金、雾蓝、墨黑或月白，主题立即应用并自动保存。
- **会话设置**：可覆盖历史条数和字数上限。每段会话也能单独设置提示词、流式输出、本机时间、记忆与世界书开关、消息字号、说话人名称、角色头像和发送后聚焦。
- **上下文**：默认发送最近 40 条消息（含最新消息）。设置字数上限后，它计算本次回复发送的文本长度。优先保留角色等提示词和最新消息，再加入能放下的世界书条目及最近的历史。被略过的消息仍保留在本机；显示更早的历史可点聊天顶部的「加载更早的消息」。

## 兼容范围

- 支持常见酒馆 PNG 和 JSON 角色卡，导入基础角色字段、头像及内嵌世界书的基础字段。角色卡可导出为 JSON。
- 世界书支持普通关键词和常驻条目，关键词在即将参与上下文的最近 6 条候选消息内匹配。
- 提示词支持 {{char}}、{{user}}、{{year}}、{{month}}、{{day}}、{{hour}}、{{minute}} 和 {{second}}。世界书高级规则和酒馆脚本不在本版兼容范围。

## 从源码构建

在项目目录用 PowerShell 运行：

    powershell -ExecutionPolicy Bypass -File .\Build.ps1

构建使用 Windows 自带的 64 位 .NET Framework C# 编译器，不需要下载依赖。构建前先退出正在运行的 WorldAI。分发时将 WorldAI.exe 与 WorldAI.exe.config 放在一起。

Android 从源码构建需要 JDK、Android 35 平台和 Android SDK Build Tools 35.0.0。在构建环境提供 WORLDAI_SIGNING_PASSWORD，再运行：

    .\Build-Android.ps1 -Jdk <JDK目录> -BuildTools <构建工具目录> -AndroidJar <android.jar> -Keystore <发行签名文件>

两个构建读取同一个 VERSION。运行 Package-Windows.ps1 可生成桌面发行 ZIP。发布正式版时，对应 GitHub 标签使用 v 加版本号，附上 WorldAI-windows-x64.zip 以及 WorldAI-android.apk。签名文件和密钥保存在私有位置。
